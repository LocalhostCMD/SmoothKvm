What this app does (and doesn't)

  • It runs only while its tray icon is there. Quit from the tray menu (or turn on "Closing the window quits SmoothKvm").
  • It runs as a background service (systemctl status smoothkvm), so it keeps working when this window is closed.
  • No accounts, no telemetry. The only internet connection it makes by itself is the update check.
  • It listens on the network only for paired computers. Anything else is refused and shown as a security alert under Activity.
  • A computer can be found on the network only while it shows a pairing code, or by a computer already paired with it.
  • Everything between computers is encrypted. Your device key is encrypted by Windows and never leaves this computer.
