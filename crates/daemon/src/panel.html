What this app does (and doesn't)

  • It runs only while this window or its tray icon is open. Closing the window quits it completely.
  • It never connects to the internet by itself, has no accounts, no telemetry and no auto-update. It only talks to the addresses you add above.
  • It listens on the network only if you turn on "Let paired computers control this PC". Anything that tries to connect without being paired is refused and shown as a security alert here.
  • Everything between computers is encrypted. Your device key is encrypted by Windows and never leaves this PC.
