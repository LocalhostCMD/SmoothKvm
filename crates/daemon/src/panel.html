What this app does (and doesn't)

  • It runs only while this window or its tray icon is open. Closing the window quits it completely.
  • It runs as a background service (systemctl status smoothkvm), so it keeps working when this window is closed.
  • No accounts, no telemetry. The only internet connection it makes by itself is the update check below (it downloads release information from GitHub; turn it off and it makes none). Updates install only when you click Update, and only if they are signed with the SmoothKvm release key.
  • It listens on the network only if you turn on "Let paired computers control this PC". Anything that tries to connect without being paired is refused and shown as a security alert here.
  • It listens for paired computers. Anything that tries to connect without being paired is refused and shown as a security alert here.
  • "Add a computer" can find computers on your network (and on Tailscale), but a computer only answers while it is showing a pairing code. Pairing still needs that code.
  • Everything between computers is encrypted. Your device key is encrypted by Windows and never leaves this computer.
