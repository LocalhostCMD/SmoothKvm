# Softwarekvm
Software KVM: Ubuntu 24.04 (KDE Plasma 6, Wayland) <-> Windows.
Ubuntu desktop holds the keyboard/mouse (server); Windows is a client.

Crates: `protocol` (messages + config), `daemon` (kvmd).
Roadmap: 1) input handoff  2) Tauri config panel + bounce animations
3) on-demand video from the DL380 G7 (virtual display, x264 over LAN).
