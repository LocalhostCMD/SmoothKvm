# SmoothKvm

> [!WARNING]
> **This project was written with AI.**
> Almost all of the code, the installers and this documentation were generated by an AI coding assistant
> (Anthropic's Claude), directed and tested by a human. It has **not** been reviewed by an independent security expert.
> SmoothKvm sends your keystrokes between computers and can install its own updates, so read the code and
> [SECURITY.md](SECURITY.md) before you trust it with anything sensitive, and use it at your own risk.

One keyboard and mouse across several computers. Your Windows PC controls other machines (Ubuntu today) as
extra screens on its left/right/top/bottom, and a Windows PC can also be controlled by another paired computer.
Everything between machines is encrypted and only paired devices are accepted.

## Install
**Windows**: run `SmoothKvm-Setup-<version>.exe` (no admin rights; Start Menu icon, optional start-with-Windows,
optional `SmoothKvm` in your terminal).
**Ubuntu / Debian**: install `smoothkvm_<version>_amd64.deb` (double-click, or `sudo apt install ./smoothkvm_*.deb`).
It starts a service on boot and adds **SmoothKvm** to the app menu (a window; no terminal needed) plus
**SmoothKvm Terminal** and the `SmoothKvm` command.

## Pairing (once per pair of computers)
1. Open SmoothKvm on both computers. The top of the window shows each computer's **name and IP address**.
2. On the computer that will be **controlled**: **+ Add a computer** → **Let another computer control this one**.
   It shows a big **8-digit code**.
3. On the **controlling** computer: **+ Add a computer** → **Control another computer**. The other computer appears
   in the list by name (on your network, or over Tailscale). Click it, pick which side of your screen it is on, and
   type the code. Done.

If it does not show up in the list, type the IP address shown at the top of the other computer's window instead.
In the terminal: `pair` shows the code in big digits; `add <name> <side> <ip>` then `pair <name> <code>` pairs.
The code is mixed into the key exchange, works once, and any wrong try cancels it. A computer only answers the
search while it is showing a code.

## Use
- **App window**: Start Menu / app menu → SmoothKvm (Linux: `SmoothKvm app`). Click a side of "This PC" to add a computer.
- **Terminal UI (both)**: type `SmoothKvm`. Commands work with or without a leading `/`; `help` lists them.
  `F2` = emergency stop, `F3` = resume. Left/Right, Home/End, Ctrl+Left/Right and Delete edit the line; Up/Down
  recall earlier commands.
- **Emergency stop**: red button, tray menu, `stop`, F2, or press **Scroll Lock three times**.
- **Send files**: drag files onto the SmoothKvm window (Windows: or onto the strip that appears at the screen edge
  while you drag), or `SmoothKvm send <files or folders> [--to <name>]`. They land in `Downloads/SmoothKvm` on the
  other computer, never overwrite anything and are never opened.
- **Effects** (Windows; colourful, drawn on screen, never move your mouse): Ripple, Glow, Sparks, Comet x Rainbow,
  Ocean, Sunset, Neon, Mono, with motion curves (bounce, elastic, spring, overshoot or your own).
- **Game mode**: no screen switching while a full-screen app or game runs.
- **Virtual display** for headless machines (Xvfb + XFCE + x11vnc through the encrypted tunnel).

## Updates
SmoothKvm checks GitHub for a new release about once a day (turn it off under **Updates** in the window). When
one is out, the window shows **Update now** (Windows: also in the tray menu; terminal: `update`). One click
downloads it, checks it, installs it and restarts SmoothKvm.
Every update is refused unless it is signed with the SmoothKvm release key built into the app, matches the signed
file hash, and is newer than what you have. On Linux the install is done by a small root helper
(`smoothkvm-helper`) that re-checks all of that itself; the app never has root rights.

## Uninstall
In the window: **Remove SmoothKvm** → *Uninstall SmoothKvm* (tick the box to also delete settings and paired
devices). Terminal: `uninstall yes` (or `uninstall yes wipe`). Or the usual way: Windows *Settings → Apps*,
Ubuntu `sudo apt remove smoothkvm`.

## Security model
- Transport: Noise_XX_25519_ChaChaPoly_BLAKE2s (mutual authentication, forward secrecy, strict nonces); pairing uses
  Noise_XXpsk3 with a code-derived key, so a man-in-the-middle cannot join. Only paired keys are accepted afterwards.
- Unauthenticated connections get 5 s and a small per-address budget. Receivers clamp every number they receive and
  release held keys if the controller goes silent for 10 s.
- Local control API: 127.0.0.1 only, 256-bit token compared in constant time, Host-header check, strict CSP and
  isolation headers. The display tunnel is one-shot (one connection, 60 s). Secret files are owner-only (0600/0700, and
  re-tightened if loosened). The Linux service is sandboxed with systemd hardening options.
- Updates: Ed25519-signed release manifest, SHA-256 of each download, no downgrades. Details in SECURITY.md.
- Known limits: a paired controller is fully trusted (it can type anything on the controlled machine); whoever holds
  the release signing key can ship updates to every installed copy.

## Build
`cargo build --release`. Windows installer: `packaging/windows/SmoothKvm.iss` (Inno Setup 6). Ubuntu package:
`packaging/linux/build-deb.sh` (or `wsl-build.sh` from Windows). Release manifest for the updater:
`packaging/make-manifest.sh <version> <setup.exe> <.deb> "notes"` (needs the release signing key), then upload
the installer, the .deb, `latest.json` and `latest.json.sig` to a GitHub release.

## Verifying downloads
Releases include `SHA256SUMS` + GPG signatures and Authenticode-signed Windows files; see [SECURITY.md](SECURITY.md).

## Transparency
The Windows app is never hidden: it always shows its window, and closing the window quits it completely. It has an
activity and security log (also `/log` in the terminal). See SECURITY.md.

## Controlling from Ubuntu
The Ubuntu machine can control your other computers too (the app is the same on every device): pair as above, then
**push the mouse off the side of the screen** where the other computer is, and push it back past that computer's
edge to return. This works on KDE Plasma: Wayland does not let normal apps see the pointer, so SmoothKvm loads a
tiny KWin script that only reports when the pointer touches a screen edge. **Scroll Lock** also switches (next
screen, again to cycle, finally back), on any desktop. Three quick presses = emergency stop. While another screen is
active, this computer's keyboard and mouse are handed to it and a notification tells you who has control. (Holding a
mouse button while crossing, to drag files or windows over, is coming next.)

## Clipboard sharing
`/clipboard on` (or the checkbox in the app) on both computers. Plain text only, up to 32 KB, only what you copy
after connecting, nothing from password managers on Windows, never written to the log. On Linux it needs
`wl-clipboard` or `xclip` (the package recommends them).
